# Preparation checklist

Updated November 13, 2026. This is an organizational checklist, not an implementation plan.

## Known team context

Five students: two Software Engineering students in Leuven, one AI student in Bologna, and two Computer Engineering students in Bologna. A sixth member, individual roles, Team Owner, final idea, and software stack are not confirmed here. Do not add private contact details to this file.

## Before opening

- [ ] All members registered for NASA Space Apps and the Universal Event.
- [ ] Members visible on the official NASA team page; Team Owner and deadline confirmed.
- [ ] GitHub invitations accepted and repository access checked.
- [ ] Generic editor/runtime/Git tools checked with an unrelated example.
- [ ] Communication channel, availability, rest periods, and handoff method agreed.
- [ ] Owners for integration, interface, data, scientific review, and submission agreed.
- [ ] Official brief, resources, submission guide, and messages read.
- [ ] Research references reviewed; no challenge code or prototype developed early.

## During the event

- [ ] Team chooses its own problem framing and solution.
- [ ] Scope and task owners recorded in issues.
- [ ] Reproducible setup and local checks documented after stack selection.
- [ ] Sources, external licenses, and AI assistance recorded as work proceeds.
- [ ] Measured, imported, and simulated data clearly distinguished.
- [ ] Prototype claims supported by appropriate checks.
- [ ] Demo and project page prepared with time left for corrections.

## Official submission checks

Use the current [Project Submission Guide](https://www.spaceappschallenge.org/resources/project-submission-guide/) as the authority.

- [ ] Demo: at most 7 slides including introductory slides, OR video at most 30 seconds.
- [ ] English project page and linked materials; non-English demo speech has English subtitles.
- [ ] Public demo and final-project links tested without login.
- [ ] NASA data/resource use explained.
- [ ] Required fields, references, licenses, and AI disclosures complete.
- [ ] Original work and terms confirmations checked.
- [ ] Submit for Judging clicked before the Team Owner's deadline.
- [ ] Successful submission confirmed; any subsequent update resubmitted before closing.

The proposed internal delivery target is Sunday 22:00 CET if the Team Owner resides in Italy or Belgium. This is a buffer, not the official deadline.

## Awards and evaluation

The confirmed five criteria are Impact, Creativity, Validity, Relevance, and Presentation. The official ten Global Awards include Best Use of Science and Best Mission Concept. These are useful evaluation references, not commitments to build particular features or promises of winning.

No separate Universal Event micro-award programme has been verified in this workspace. Check official messages and any sponsor-specific rules before assuming eligibility.
